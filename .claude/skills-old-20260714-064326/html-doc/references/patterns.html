Workflow Skills  /  output redesign

Every plan and record
is now a built artifact.

The workflow skills no longer hand back stiff documents. Each skill now asks one question first — what would let you actually see this? — and builds a purpose-shaped HTML artifact for it. Detail that doesn't earn its place is folded away or kept by the agent. What's left is visual.

Pick the shape

A comparison grid, a prototype, an explainer, a board — the format follows the task, never a fixed template.

Show, don't tell

Mockups, diagrams, real toggles and sliders instead of paragraphs describing them.

Fold the noise

The essence stays on screen. Deep detail lives behind a disclosure or with the agent.

Plan · debounced search

Wire the search box to the API

Data flow
Steps
▸01 Hold one controller per requestsearch.ts:14
Keep a module-level AbortController. On each keystroke, call .abort() on the old one before creating the next — the previous fetch rejects quietly and never paints stale results.
▸02 Debounce the keystrokesearch.ts:21
300 ms timer, reset on every input. Only the trailing call survives.
▸03 Swallow the abort errorsearch.ts:33
A cancelled fetch throws AbortError — catch it and return, don't surface it to the user.
Config
let ctrl;
async function search(q) {
  ctrl?.abort();
  ctrl = new AbortController();
  try {
    const r = await fetch(`/api/search?q=${q}`, {signal: ctrl.signal});
    render(await r.json());
  } catch (e) { if (e.name !== 'AbortError') throw e; }
}

Edge cases & rejected alternatives
Empty query short-circuits before fetch. Network failure keeps the last good results and shows an inline retry. rxjs was rejected on bundle size — see Pattern 01.

Nothing here is a fixed template. The html-doc skill carries the design system and these patterns as reference; the agent composes the page that fits. Every file is self-contained, light, and opens in the browser the moment it's written.
