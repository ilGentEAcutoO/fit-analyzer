PROMPT CALIBRATION · 3 ROUNDS

How the moderate case landed at "strong"

User feedback drove the calibration: "ของจริงคนใช้คือ candidate ที่ partial fit, ไม่ใช่ Senior backend สมบูรณ์แบบ"

R1 · honest baselineMOD = 45 · weak ✗
"Be honest. A weak match must read as weak." — model interpreted JD's "no bootcamp-to-prod" + "3+ years" as hard filters → harsh.
R2 · gentle softenMOD = 55 · moderate ↑
"Lean toward moderate or strong when core stack present, even with seniority gap." — crossed threshold but only just.
R3 · algorithmic floor (FINAL)MOD = 76 · strong ✓
3-step process: classify stack overlap (FULL/NO/ADJACENT) → set overallScore from classification → recruiter sanity check (shortlist-worthy ⇒ at least moderate). Forces algorithmic reasoning instead of "feel".

STRONG case stayed at 92→95 throughout (Jane senior backend × senior backend JD). WEAK case stayed at 0→15 (Somchai marketing × backend distributed) — proves the floor only lifts cases with real stack overlap.
